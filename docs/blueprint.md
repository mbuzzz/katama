## Style Guidelines:

- Primary color: Soft beige (#F5F5DC) for a warm and inviting feel.
- Secondary color: Creamy white (#FFFDD0) for backgrounds and text.
- Accent color: Light pink (#FFB6C1) for interactive elements and highlights.
- Friendly and slightly rounded sans-serif fonts for a welcoming atmosphere.
- Clean and organized layout with ample spacing for easy readability.
- Simple and charming icons to represent different product categories and actions.
